# AI Resume Analyzer
An end-to-end AI-powered Resume Analyzer built using Python, Flask, and NLP techniques to intelligently evaluate resumes against job descriptions. The system extracts content from PDF/DOCX resumes, identifies skills, education, and experience, and performs semantic matching using transformer-based embeddings.
